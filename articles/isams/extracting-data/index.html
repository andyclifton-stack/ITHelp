Extracting Data

iSAMS

Follow the steps below to export student data from iSAMS into a spreadsheet.

Export student data

  1. Open iSAMS.
  2. Navigate to Student Manager.
  3. Enter search criteria if required.
  4. Select the students whose data you want to export.
  5. Open the pink dropdown on the right-hand side and select "Export Wizard".
  6. Select "Create a custom report", or select an existing report if appropriate.
  7. Click Next.
  8. Select the data fields you want to export and click Next.
  9. Review the preview of the data to be exported and click Next.
  10. Select .xlsx or .csv, depending on your requirements, and click Next.
  11. Click the download link when the export is ready.
  12. Open the file in Google Sheets or Microsoft Excel.
