Emailing a Correspondent

  1. Open the Student Manager module.
  2. Select the Current Students tab and use the Basic tab to search for the student record(s) that you want to work with
  3. Click Search to find student records
  4. Select the checkboxes by the students you wish to send an e-mail to
  5. Use the P/S drop down list to change the number of records you wish to work with from the search results. For example, if you want to select all records from the search results (not only the results displayed in the page), select 'P/S - All'.
  6. Open the pink drop down list in the top right of the screen and select Email Wizard. The Email Wizard is displayed.
  7. Check the box for Contacts for the selected students
  8. Click Next
  9. Select all relation types
  10. Go to the "Filter by Contact Type" and tick correspondence - IMPORTANT
  11. Tick/untick who you want to email
  12. Click next
  13. Type your email
    Email templates are avaliable
  14. Select the Recipients tab and confirm the recipients of the e-mail
  15. Select the Attachments tab and upload attachments, as required.
    You can also delete attachments uploaded in error from this screen.
  16. Use the Options tab to set e-mail properties
  17. Click Send E-Mail
  18. Click View Summary to check on the status of the e-mail delivery
