How To View a Timetable

iSAMS

Viewing a Students Timetable

  1. Log into iSAMS
  2. From the Wizard Bar , expand the Timetable Manager category
  3. Click on View Student Timetable from this sub menu
  4. Search for the Student using their name
  5. Click on them to select their profile
  6. Select the file format you wish to use
