Adding a Hyperlink to an Email

Google Workspace

Using descriptive link text can make an email easier to read than displaying a long web address.

Add a hyperlink in Gmail

  1. Compose a new email.
  2. Press Ctrl + K to open the link window.
  3. Enter the text that recipients should see.
  4. Paste the URL into the web address field.
  5. Click OK.

To add a link to text you have already written, highlight the text and press Ctrl + K, then paste the URL.

Add a hyperlink in Outlook

  1. Compose a new email.
  2. Press Ctrl + K, or select the Insert tab and choose Link.
  3. Enter the text that recipients should see.
  4. Paste the URL into the address field.
  5. Click OK.
