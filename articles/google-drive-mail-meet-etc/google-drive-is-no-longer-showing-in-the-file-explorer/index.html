Google Drive is no longer showing in the file explorer

Google Workspace

Your Google Drive files can be accessed through the browser but if you're working on a desktop computer you may find it quicker to access them through Windows file explorer. Below are a few common issues.

Google Drive showing but can't access files

This can happen for any number of reasons but it's usually very quick to fix:

  1. Click on the windows menu
  2. Type in "Google Drive" - If you can't find it follow the section below to install it
  3. Click on "Google Drive"
  4. It is likely to look like nothing has happened but hopefully, you will now be able to access the files. If not, continue to the next steps.
  5. Click on the arrow next to the clock in the bottom right corner and then double click on the Google Drive icon.
  6. When prompted, enter your Google account details (it may have these already from your browser) and accept the permissions

Google Drive is not installed

You shouldn't normally need this step as your desktop PC should have it installed but it's useful to know if you need to use another computer (Remote work etc)

  1. For PC follow this link > https://dl.Google.com/drive-file-stream/GoogleDriveFSSetup.exe
  2. For Mac follow this link > https://dl.Google.com/drive-file-stream/GoogleDrive.dmg
  3. Follow the given instructions on the install packages
  4. Submit a ticket to the service desk if you have any issues
