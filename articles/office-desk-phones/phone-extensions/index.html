Instructions for checking a number in the corporate directory on a Cisco IP 504G phone:

  1. Press the "Directory" button on the phone.
  2. Select "Corporate Directory" using the navigation button.
  3. Enter the name or number you are looking for using the keypad.
  4. Press "Submit" to search.
  5. Scroll through the results using the navigation button.
  6. Select the desired contact to view details or press "Dial" to call.
