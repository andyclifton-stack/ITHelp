Classlink

It is a requirement to have multi-factor authentication for all staff accounts. It only takes a couple minutes to set up.

You’ll only need MFA when signing in off-site, not while on the school network

Adding an MFA method


1. Go to: https://mysignins.microsoft.com/security-info

2. Sign in with your school email and password

3. Add a sign-in method:

  • Microsoft Authenticator app (recommended) – follow the steps to scan the QR code
  • or Mobile number (SMS) – get a text code to verify
