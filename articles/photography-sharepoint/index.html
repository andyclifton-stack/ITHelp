Accessing a SharePoint Site

  1. Go to office.com and sign in with your school account
  2. Once logged in, click on the SharePoint icon from the list of apps.
  3. From the sharepoint homepage click on "Photography"

Adding a SharePoint Shortcut to OneDrive (Without Syncing Files)

  1. Follow the steps above to access your SharePoint site.
  2. Go to the document library (or folder) that you want to create a shortcut for.
  3. In the document library, select the folder you want to add as a shortcut.
  4. Click on the "Add shortcut to OneDrive" button usually found at the top menu bar.
    If you don't see this option, click on the ellipsis (three dots) next to the folder and then select "Add shortcut to OneDrive" from the dropdown menu.

Accessing the Shortcut in OneDrive

  1. Open file explorer (yellow folder)
  2. Click on OneDrive
  3. Shortcut files can be found here

Accessing the Shortcut in OneDrive (online)

  1. Go to https://claremontschoolcouk-my.sharepoint.com/
  2. In your OneDrive, you will see the added shortcut in the main directory. It will appear with a link icon indicating it is a shortcut.
    Ensure that you do not click the "Sync" button in the OneDrive web interface, which would start the syncing process.
