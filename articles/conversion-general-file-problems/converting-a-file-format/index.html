Very easy but also very useful one, changing a file format e.g. a .wma file to .mp3 file

Changing a file format

  1. Use Google to search for what you want to go from and to (e.g wma to mp3, HEIC to jpg etc)
  2. Open one of the websites from the results, the two I use most ffrequently are CloudConvert and FreeConvert
  3. Upload the file to the website, change any settings to fit your needs and hit convert
  4. Download finished file (sometimes websites auto download upon completion)
