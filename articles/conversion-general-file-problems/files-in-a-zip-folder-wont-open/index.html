Files in a ZIP folder won't open

Files & Conversion

ZIP folders are basically like presents, they have been packaged up and need to be unwrapped to access what is inside.

Unzip a folder

  1. Navigate to the ZIP folders location
  2. Right click and click "extract all"
  3. Check extract location (where the folder will end up) by default this is the same parent folder of the zip
  4. Click "extract"
