Changing default programs (e.g browser)

  1. Open the start menu, search for and open "Default Apps"
  2. Scroll down to "Web browser"
  3. Click on the current program associated with it to change it


Changing default programs for file types (e.g pdf)

  1. Open the start menu, search for and open "Default Apps"
  2. Scroll to the bottom and click on "Choose default applications by file type"
  3. Scroll down to .pdf
  4. Click on the current program associated with it to change it
